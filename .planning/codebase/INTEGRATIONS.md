# External Integrations

**Analysis Date:** 2026-06-23

## APIs & External Services

**None.** This is an offline, locally-run tabletop game. No code in the repo makes network calls, calls a remote API, or talks to any cloud service. All Python scripts (`simulate_outcomes.py`, `analyze_simulation_results.py`, `balance_analysis.py`, `generate_attack_calculator.py`, `generate_from_template.py`, `generate_pptx_cards.py`) operate purely on local files (read config/JSON, write JSON/xlsx/pptx). There is no `requests`, `urllib`, `http.client`, or SDK-client import anywhere in the codebase.

## Data Storage

**Databases:**
- None. No database client, ORM, or connection string exists in the repo.

**File Storage:**
- Local filesystem only. All "storage" is plain files in the repo working tree:
  - `simulation_config.json` — read by `simulate_outcomes.py` (via `--config`, default `simulation_config.json`) and optionally by `analyze_simulation_results.py` (via `--config`) for RoS weighting.
  - `sim_low.json` (14 MB) / `sim_med.json` (52 MB) — pre-generated simulation output for the "low" and "medium" budget tiers, written by `simulate_outcomes.py` and consumed by `analyze_simulation_results.py` and `balance_analysis.py`.
  - Gitignored variants `simulation_results.json`, `simulation_results_low.json`, `simulation_results_medium.json`, `simulation_results_high.json`, `sim_high.json` — local working output not committed (per `.gitignore`), except that three of these filenames (`simulation_results.json`, `simulation_results_high.json`, `sim_high.json`) are simultaneously declared as Git LFS-tracked in `.gitattributes`, implying they are sometimes intentionally checked in via LFS despite also appearing in `.gitignore` — this is an inconsistency worth flagging if those files are expected to be versioned.
  - `pptx_output/` — output directory for `generate_pptx_cards.py` (hardcoded path: `Path(__file__).parent / "pptx_output"`), containing generated PPTX card decks (`Events.pptx`, `Events_Generated.pptx`, `Massnahmenkarten.pptx`, `Massnahmenkarten_Generated.pptx`, etc.).
  - `final_documents/` — finished/print-ready game material (docx/pptx/pdf), not directly written by a script in this repo (per `CLAUDE.md`, these are regenerated from generator scripts/source templates, not hand-edited, but the repo does not show an automated script writing directly into `final_documents/` — likely a manual copy/export step from `pptx_output/` or Office tooling).
  - `angriff_berechnung.xlsx` — Excel attack-damage calculator generated by `generate_attack_calculator.py` using `openpyxl`.

**Caching:**
- None.

## Webhooks & Callbacks

## Summary

This repository has **no external integrations**. The only "integration points" are file-to-file: a JSON config file drives Python scripts that read/write other JSON files and generate Office documents (xlsx/pptx) consumed by humans for printing and live facilitation. Git LFS (declared in `.gitattributes`) is the closest thing to external infrastructure, used solely to manage large generated JSON result files in version control.
