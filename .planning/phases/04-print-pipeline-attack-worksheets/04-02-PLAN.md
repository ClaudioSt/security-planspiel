<objective>
Build the attack-worksheet print model: one `AttackSheet` per wave that holds the exact values a facilitator calculates with and the German display strings the template will print, both derived from `simulation_config.json` and `content/texte.toml` (PRINT-03). Derived constants (cap, Obergrenze, euros per severity point, Fall-1/Fall-2 outcomes, slope, bonus rows, recovery table) come from one new `rules.py` helper so the single-definition guard stays green (research Pitfall 3). The model enforces the hand-calculation guards D-06 (rearranged damage formula only while base_severity = mitigation_cap and multiplier = 1) and D-09 (two decimal places never flip the per-wave rounding), formats the slope exactly (D-08) and carries the new step wording.

Purpose: the template (plan 04-06) only inserts strings, and the equivalence replay (plan 04-04) reads only this model's exact fields, so sheet and proof share one source (D-11).
Output: `rules.worksheet_constants` and its NamedTuples, `planspiel/fmt.py`, `planspiel/printmodel.py`, new `[sheets.angriff]` wording, tests.

Scope boundaries: Jinja templates, `print/planspiel.sty` layout macros and the PDFs are plan 04-06; the replay and grid tests are plan 04-04. No change to simulation behaviour: `rules.py` only gains a read-only helper.

D-05 decision taken here (Claude's discretion): the CIA table gets `len(cfg.measures)` blank rows. Measured on the real config (full enumeration of dependency-valid plans within budget), 6 rows cover 77.9 % (low), 66.5 % (medium) and 55.7 % (high) of in-budget plans, 8 rows cover 99.6 / 98.7 / 97.2 %, and 10 rows cover every plan. Plan 04-06 splits the sheet deliberately onto two pages, which leaves room for 10 rows at 7 mm.

Rounding wording (orchestrator note, research Pitfall 8): the D-10 phrase "ab ,5 vom Betrag aufrunden" keeps its MHP form through one reviewed allowlist entry. ",5" names the fixed rounding rule implemented in `rounding.round_half_away` (not a config value), like the existing "3-2-1" entry. The pinned allowlist set grows from seven to eight entries in a deliberate test change.

Printed cap (PRINT-03 "caps", ROADMAP SC2): the MHP sheet only implied the cap through the Obergrenze 31. This plan prints it as a number: `WorksheetConstants` and `AttackSheet` carry the integer `reduction_cap` (the attack's mitigation cap; the field name avoids the guarded operand name), and the Fall step opens with a cap intro plus the cap line "Schwelle: 23 · Kappung: 8 · Obergrenze: 23 + 8 = 31" (labels digit-free in `[sheets.angriff]`, numbers from the model).

Language rule (user's global rule, orchestrator decision): new code comments and docstrings are English. German is used only for user-facing console output (e.g. `WorksheetInvariantError`/`PrintModelError` messages, which `planspiel print` shows as `ERROR print.model …`) and for printed content, which comes from `texte.toml`. Existing docstrings are not rewritten.
</objective>
