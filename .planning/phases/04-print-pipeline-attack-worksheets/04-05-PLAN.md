<objective>
Put a version stamp on every generated page and make stale printouts detectable (PRINT-11, ROADMAP SC4). The stamp is "Stand <date> · <hash>" (+ "+lokal" on a dirty tree): the hash covers the rendered content of the whole print set plus the style (D-19), the date is the last commit of the data inputs (D-15), and `stamp.tex` sits outside the hash. `planspiel print` writes a manifest and `planspiel print --check` reports stale PDFs without running TeX (D-20).

Purpose: at the table, mixed old and new printouts are visible at a glance, and the maintainer can check whether the committed PDFs match the current inputs.
Output: `planspiel/stamp.py`, stamp slot in `print/planspiel.sty`, stamp and manifest wiring in `planspiel print`, `--check`, tests.

Scope boundaries: the worksheets themselves are plan 04-06; it builds and commits them with this stamp in the D-19 order. The stamp tests iterate the whole print set, so the worksheets are covered once they are registered.

Hard rules for the executor: never run kpsewhich without `--miktex-disable-installer` or lualatex without `--disable-installer`, always with a timeout; never touch MiKTeX (D-17); git calls in code use argument lists and a timeout; always `uv run`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| committed PDFs → classroom | Printouts may be stale or mixed |
| git metadata → stamp | Dates and dirty state come from the repository |
| out dir → maintainers | Files there must not be hand-edited |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-16 | Repudiation | stale or mixed printouts treated as current | high | mitigate | Content-hash stamp on every page (pdf test), one stamp per set, committed manifest, `planspiel print --check` |
| T-04-17 | Tampering | hand-edited PDFs in `final_documents/generated/` | medium | mitigate | `pdf_sha256` in the manifest; `--check` reports a mismatch; `planspiel print` removes orphan PDFs |
| T-04-18 | Tampering | stamp feeding back into its own hash or a rebuild marking itself dirty | medium | mitigate | `stamp.tex` written after hashing and outside the hashed set; dirty pathspecs exclude output dirs (tests in a temp repo); recorder check |
| T-04-19 | Tampering | command injection through git calls | low | mitigate | Fixed argument lists, `-C <repo>`, constant pathspecs, timeout; no shell |
| T-04-20 | Information disclosure | absolute paths or user names in the stamp or manifest | low | mitigate | Stamp holds only date and hash; manifest holds file names relative to the out dir and hashes |
</threat_model>
