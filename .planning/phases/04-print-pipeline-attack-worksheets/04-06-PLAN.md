## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model strings → LaTeX template | Strings from config and texts become TeX input |
| committed PDFs → classroom | Teams and facilitators calculate from the printed numbers |
| file names → pre-wave material | Revealed sheets name the attack |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-21 | Tampering | arithmetic or logic in the template bypassing the model | medium | mitigate | Template lint (every `\VAR` a plain name/attribute/subscript); fragments-in-tex and fragments-in-PDF tests; StrictUndefined |
| T-04-22 | Tampering / Elevation of privilege | LaTeX specials in measure names or texts | medium | mitigate | Every value passes `tex_escape` (finalize); render test checks `Backup \& Disaster Recovery`; no shell escape |
| T-04-23 | Repudiation | PDFs committed from a dirty tree or out of date | high | mitigate | D-19 order with a clean `git status` gate, manifest `"dirty": false`, `planspiel print --check` exit 0, byte-identical rebuild check |
| T-04-24 | Information disclosure | attack names in the worksheet file names | low | accept | Attack worksheets are revealed material handed out when the wave hits (Phase 3 D-13/D-27; CONTEXT allows naming files after the attack); Phase 5's VEIL-02 scan covers only pre-wave material |
| T-04-25 | Tampering (integrity of printed numbers) | layout hiding or truncating a number (overflow, missing glyph) | medium | mitigate | Two-page test, step-placement test, no "Missing character"/"Overfull \hbox" in the logs, human print check |
</threat_model>
