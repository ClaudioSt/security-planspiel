<objective>
Move every German prose text used on print material into one content source, `content/texte.toml`, keyed by config id, and strip prose from `simulation_config.json` (PRINT-02, ROADMAP Phase 3 SC1, SC2, SC5). A loader and lint module `planspiel/texts.py` with the CLI `planspiel texts` guards the source: coverage against config ids and declared sheet/story lists, a strict digit lint with a reviewed allowlist, and a story mechanics lint. The config strip changes text in the pinned characterization goldens; that change is proven text-only and rewritten only after the user approves (D-08, D-25). The plan also produces the SC5 inventory and the git-tracked assets folder (D-19, D-22).

Purpose: printed numbers must come from config, never from typed prose, and templates in Phases 4/5 must contain layout only. One edit point for wording removes the print/sim mismatch sources found at MHP.
Output: `planspiel/texts.py`, `planspiel texts`, `content/texte.toml`, `content/digit_allowlist.toml`, `content/INVENTORY.md`, `content/assets/`, prose-free config, `schema.prose_in_config`, text-only golden update, `03-01-GOLDEN-DIFF.md`.

Scope boundaries: attack texts are carried verbatim into `attacks.<id>.revealed.*`; the veiled key, title generation, audience views and giveaway lint are plan 03-02 (VEIL-01). Story texts are carried verbatim and un-veiled; veiling and the clue matrix are plan 03-03 (VEIL-03). The un-veiled story text in TOML is never printed in this phase (PDFs are Phase 5).
</objective>
