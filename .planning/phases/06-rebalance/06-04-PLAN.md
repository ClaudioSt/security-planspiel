    - On the mini config (all tiers) every function equals a brute force that loops over all pairs of plans differing in one measure (shares, swings), filters in-budget plans within the band (band shares), and recomputes the tier best with the measure forced to 0 (removal drops).
    - `near_optimal_band` with band 5 returns all in-budget rows with kz ≥ best − 5; if fewer than `min_size` rows qualify it returns the `min_size` best rows ordered by (−kz, own_cost, code).
    - `tier_band_jaccard({"low": A, "medium": B})` equals |A ∩ B| / |A ∪ B| on code sets.
  </behavior>
  <action>
    1. planspiel/choices.py (new, German module docstring): threshold constants (Claude's discretion, proposals for D-04 from research Q7): `BAND_KZ = 5`, `BAND_MIN_SIZE = 200`, `NEAR_MANDATORY_SHARE = Fraction(9, 10)`, `OVERPOWERED_DROP = 10`, `DECISION_SHIFT_KZ = 3`, `DECISION_SHARE = Fraction(1, 2)`, `TIER_JACCARD_MAX = Fraction(1, 2)`.
    2. Functions (pure; columns or arrays in, numbers out; Fractions for shares):
       - `kz_grid(n_measures, code_index, kz_final, over_budget) -> array` ("b", -1 for invalid or over budget).
       - `level_improvement_shares(grid, n_measures) -> Dict[Tuple[int, int], Fraction]`: for each measure j and level l ≥ 1, contexts = codes with digit j == l and grid[code] ≥ 0 that have at least one lower level of j with grid ≥ 0; share = contexts where grid[code] > max over lower levels with grid ≥ 0, divided by contexts; a (j, l) without any context gets share None (reported, not a failure). `strictly_dominated(shares)` returns the (j, l) with share 0.
       - `level_swing_shares(grid, n_measures, shift=DECISION_SHIFT_KZ) -> Dict[int, Fraction]`: per measure, over contexts (the other digits fixed) with at least two in-budget levels, the share whose max − min final KZ over those levels is ≥ shift.
       - `near_optimal_band(code_index, kz_final, own_cost, over_budget, band=BAND_KZ, min_size=BAND_MIN_SIZE) -> List[int]` (codes).
       - `band_shares(codes, n_measures) -> Dict[int, Tuple[Fraction, Fraction]]` (share level ≥ 1, share level ≥ 2); `near_mandatory(shares, threshold=NEAR_MANDATORY_SHARE)` returns measure indices with share level ≥ 1 > threshold.
       - `removal_drops(grid, n_measures) -> Dict[int, int]`: tier best minus best over codes with digit j == 0.
       - `tier_band_jaccard(bands_by_tier) -> Dict[Tuple[str, str], Fraction]`.
       Use stride arithmetic like gate.lowering_closure; no access to OPERAND_ATTRIBUTES (`.init`, `.bonus`, `.weights`, …); no builtin round.
