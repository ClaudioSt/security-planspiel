<objective>
Build the BAL-02 check test-first: the hand-calculability findings of the validator get a severity parameter so they can be errors (D-03: at most one decimal place for every worksheet slope and constant; no 17/7-type slope). The default stays "warning" because promoting it now would make `load_config(simulation_config.json)` raise and stop the suite and `planspiel print`; plan 06-10 flips the default together with the adopted config (research Q4 sequencing). Until then the tuning plan gates candidates with `planspiel validate --strict --config <cand>` (warnings exit 1) and with the slow check built here.

Purpose: makes "validator warnings become errors" a one-line switch that is already tested, and gives the tuning plan a hard hand-calc gate on candidates.
Output: `hand_calc_level` in planspiel/validate.py, new code hand_calc.final_index_weights, tests/test_hand_calc_level.py.
</objective>
