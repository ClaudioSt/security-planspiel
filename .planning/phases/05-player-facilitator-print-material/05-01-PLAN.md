<objective>
Build the automated veil scan of VEIL-02 before any new document exists, so every later Phase 5 document is classified and scanned the moment it is registered (research "Plan Order": VEIL-02 first). The scan has two layers: layer 1 runs on the rendered `.tex` in the default suite and as a build gate in `planspiel print`; layer 2 runs on the built PDFs in the `-m pdf` suite and also covers metadata and file names. A job-prefix audience registry makes the pre-wave / practice / revealed / facilitator split explicit (CONTEXT, Claude's discretion on the veil scan).

Purpose: ROADMAP SC5 ("an automated scan of all pre-wave material — text, file names, PDF metadata — finds no attack names and no wave CIA weights") becomes a permanent, failing-by-default gate instead of a one-off review. It closes the technical half of the folded todo "Angriffe und Aktionen nur indirekt vermitteln" (moved to completed in plan 05-10).
Output: `planspiel/audience.py`, `planspiel/veil.py`, the `print.veil` gate, `tests/support/pdf_text.py`, four new test files, prefix-aware fixes of the existing print tests.

Decisions honoured: Phase 3 D-13/D-13b/D-20 (veil timing, giveaway list, story exceptions), D-24 (names-only profile for the measure deck), VEIL-02 coverage (text, file names, metadata). Weight detection (Claude's discretion): a window of three consecutive number tokens equal to a real wave's formatted triple, plus the joined form in whitespace-squashed text, plus a weight symbol followed by a value (`wC = 0,4`) on pre-wave documents; the bare symbols `wC wI wA` without values stay legal (legend card, wave explainer).

Research findings applied: F1 (weights only through `rules.worksheet_constants`), F5 (hard-coded job lists), F9 (Phishing on M6), F10 (pypdf drops spaces: token terms only at layer 1), F11 (revealed sheets checked against other attacks by full name, not stems). Case texts (`case_1..3`) are not attack-specific (wave 1 and 2 share "Ihr mindert die Auswirkungen teilweise."), so they are excluded from the revealed-string list.

Hard rules for the executor (all Phase 5 plans): run Python only via `uv run`; never touch MiKTeX (Phase 4 D-17); never write to `final_documents/generated/` (only plan 05-10 regenerates the set; preview builds go to `uv run planspiel print --out-dir build/preview --build-dir build/print`); code, comments and docstrings in English, printed text and console messages in German; TDD: RED commit `test(05-01): ...` with the failing run quoted in the SUMMARY, then GREEN commit `feat(05-01): ...`.
</objective>
