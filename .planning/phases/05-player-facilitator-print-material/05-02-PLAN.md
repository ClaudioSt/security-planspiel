<objective>
Generate the measure deck (PRINT-05): 30 level cards and one legend card on A6, four per A4 sheet, every number from config through `rules`, wording from `content/texte.toml`, through the existing Jinja -> LuaLaTeX pipeline. This plan also owns the shared card machinery that plan 05-04 reuses for event cards (deck model shape, `karten.tex.j2`, card macros in `planspiel.sty`, TikZ probe) and the generic log-hygiene pdf test over every job.

Purpose: ROADMAP SC1 (measure cards with a "how to read this card" legend, generated by the one print command) and the card half of the Init decision "measure cards show CIA/costs/dependencies only".
Output: `planspiel/cards.py`, `rules.card_facts` / `rules.level_requirements`, `print/templates/karten.tex.j2`, card macros, tests, and a human-approved printed sheet.

Decisions honoured: D-01 (one card per level), D-02 (A6, four per A4, cut lines), D-03 (separate legend card with callouts), D-04 (plain plus technical text; CIA, Init, OPEX; no weights, bonus links or attack names), D-05 (one deck per build), D-06 (lock icon plus `M2 ≥ L2`, nothing without dependency), D-07 (single-sided; duplex backs not built), D-24 (names-only scan profile; Phishing stays on M6), D-25 (euros with thousands dot), D-26 (stamp once per A4 sheet in the bottom strip). Phase 4 IN-04 (`\levelbadge` error branch) and IN-09 (missing glyphs) are closed for all documents here.

Design choices (Claude's discretion, recorded): legend card first, then M1 L1 ... M10 L3 in config order; card title uses the same `M1 – IAM/PAM` form as the worksheet bonus table so players match cards and worksheets; the lock icon is drawn in TikZ because Arial lacks lock/box/tick glyphs (research "Standard Stack"); plain TikZ cells, no `tcolorbox`/`tikzfill` skins; body 9 pt, `levels_desc` 7.5 pt, with the fallback order in Task 3.

The measure-card field set is designed so plan 05-03 (VEIL-04) can pin it: descriptive texts plus CIA values, costs and dependency only; no field for weights, bonus, wave or attack.

Hard rules: `uv run` only; never touch MiKTeX (packages `pgf` are already installed, research "Environment Availability"; only the probe and the list entry are added); no write to `final_documents/generated/` (preview: `uv run planspiel print --out-dir build/preview --build-dir build/print`); English code and comments, German printed text; every new `sheets.*` key also goes into `tests/fixtures/mini_content/texte.toml` in the same commit (Pitfall 4); TDD with RED commits.
