---

## Sampling Rate

- **After every task commit:** Run `uv run pytest -q`
- **After every plan wave:** Run `uv run pytest -q` plus `uv run pytest -q -m slow -k "digest or perf"` for the tier(s) touched
- **Before `/gsd-verify-work`:** Full suite green (`-m "slow or not slow"`), fresh-clone command green, `uv run planspiel validate` shows exactly the one expected warning
- **Max feedback latency:** 15 seconds (quick suite)
