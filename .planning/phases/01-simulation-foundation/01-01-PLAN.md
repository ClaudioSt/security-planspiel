| PATH interpreter → uv | A foreign interpreter (Inkscape, Store) could be picked up instead of the managed one |
| test process → subprocess | Tests spawn the console script and the root scripts |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-SC | Tampering | `uv add` / `uv sync` (pytest, openpyxl, python-pptx, uv_build) | high | mitigate | Exact `==` pins, hashes in committed `uv.lock`, fresh-clone run uses `--locked`; packages confirmed canonical (research Package Legitimacy Audit + orchestrator resolution); no unaudited package added |
| T-01-01 | Spoofing | interpreter selection | medium | mitigate | `.python-version` 3.12 + `python-preference = "only-managed"`; `test_interpreter_is_project_venv` asserts `sys.prefix` is the repo `.venv` and the base interpreter is not Inkscape's |
