<objective>
RISK-03: add a "gegen R#" column to the planning table on the Teamheft planning page so teams can link each planned measure to one or more register risks, marked as a recommendation.

Purpose: the chain's third link (risk -> measure). Linking measures to register risks makes the budget decision a risk decision; D-10 keeps it a recommendation so no rule, penalty or facilitator check is added.

Output: the fifth planning column and its hint, the measures-block direction note, README step 4, tests.

Decisions honoured: D-09 (column "gegen R#", one or more risks per measure), D-10 (recommendation, no penalty, no rule change, no facilitator check), D-23 (README part; the Was-ist-neu sheet has no line about the planning table, so it stays). Layout from RESEARCH § RISK-03: `\tabcolsep` 4 pt and columns Level 14 mm, Init 20 mm, OPEX 25 mm, gegen R# 22 mm keep the X column at about 197 pt (no label wraps; the longest label is 187.8 pt).

Hard rules: `uv run` only; prose only in `texte.toml` (no digits, so the example "R1, R3" is written as words such as "mehrere durch Komma getrennt"); templates only loop and place; the committed print set is not touched.
</objective>
