Output: `AttackSheet.reality_line`, two texts, the template line, a practice-config fix, the golden re-pin, README step 5, tests.

Research A8: Welle 0 gets no line. Correction to RESEARCH § RISK-04: `practice_config` builds its config with `dataclasses.replace(cfg, …)`, which would carry `risk_matrix` over; this plan sets `risk_matrix=None` there explicitly so the practice sheet stays unchanged.

Hard rules: `uv run` only; prose only in `texte.toml`, digit-free; templates only place; re-pin the golden only in GREEN with a note in the commit body; the committed print set is not touched.
</objective>
