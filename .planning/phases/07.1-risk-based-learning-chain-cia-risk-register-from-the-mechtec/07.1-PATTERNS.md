## Pattern Assignments

### `planspiel/config.py` (RISK-01, RISK-05, RISK-07) - model, transform

**Analog:** `SessionSchedule` and its loader.

Dataclass style (config.py 96-114): plain `@dataclass`, defaulted fields last, docstring says who reads the block.
```python
@dataclass
class SessionSchedule:
    """Session schedule and print list: read only by the facilitator print models ... never by rules or enumeration."""
    total_minutes: int
    ...
    debrief_stages: tuple[DebriefStage, ...] = ()
```
Loader (config.py ~262-281): optional block guarded by `if "..." in raw`, tuples built in the constructor call, `block.get(...)` for optional keys.
```python
session_schedule = None
if "session_schedule" in raw:
    block = raw["session_schedule"]
    session_schedule = SessionSchedule(
        ...
        debrief_stages=tuple(
            DebriefStage(id=item["id"], minutes=item["minutes"]) for item in block.get("debrief_stages", [])
        ),
    )
```
Copy: `risk_matrix = None; if "risk_matrix" in raw: ...` and append `risk_matrix: Optional[RiskMatrix] = None` to `Config` after `practice` (only constructor call is the `return Config(...)` at ~282). `pitch_seconds` becomes a defaulted field on `SessionSchedule` loaded with `block.get("pitch_seconds")`. Use `RiskBand.minimum` (JSON key `min`).

### `planspiel/rules.py` (RISK-01) - utility, transform

**Analog:** `base_losses` (rules.py 626-631), the very function to refactor.
```python
def base_losses(waves: List[Wave], attacks: Dict[str, Attack]) -> int:
    total = 0
    for wave in waves:
        attack = attacks[wave.attack_id]
        total += attack.base_severity * attack.s_unit
    return total
```

## Shared Patterns

### Optional config block, absent in the mini fixture
**Source:** `planspiel/config.py` 250-281, `planspiel/texts.py` 385-399, `tests/fixtures/mini_config.json`

### Single definition of operands
**Source:** `planspiel/rules.py` 626-631, `tests/test_single_definition.py` (`OPERAND_ATTRIBUTES` ~95, test ~153)
**Apply to:** `risk.py`, `cheatsheet.py`, `booklet.py`. Use `rules.unprotected_damage`.

### Finished strings, templates only place
**Source:** `planspiel/booklet.py` (`fmt.format_money`, `fmt.format_number`), `.claude/CLAUDE.md` "Print model rules"
**Apply to:** all new models and templates. R-labels, rank range, band limits and "60 Sekunden" are composed in code from config; the digit lint rejects digits in `texte.toml`; no number words for config counts (`tests/test_texts_number_words.py:15-18`, add `sheets.register` and `sheets.cheatsheet` to `PHASE7_PREFIXES`).

### Fill report and page pins
**Source:** `teamheft.tex.j2` (`\fillreport{\thepage}` + `\clearpage`), `master.tex.j2` (`\pagereport`), `tests/test_booklet_pdf.py` (page count at ~42, no Overfull at ~123, fill count follows `len(pages)`)
**Apply to:** RISK-02, -03, -04, -05, -07. Every new page ends with a fill report and is proven by the pdf test; update page-count and order pins in the RISK-02 RED commit.

### Veil check of new text
**Source:** `veil.name_hits(text, ctx, audience.PROFILE_STORY)` as used at `tests/test_schedule_model.py:146` and `tests/test_debrief_model.py:134`
**Apply to:** register texts and example, cheat-sheet cases (spoken aloud before the waves), reality-check line (attack-neutral), debrief questions.

### Strict TDD order
RED test committed first, then GREEN; golden re-pin only in GREEN with a note in the commit body; the committed print set (`final_documents/generated/`) only in RISK-10. Change order inside each plan: config, README, `texte.toml`, then print.
