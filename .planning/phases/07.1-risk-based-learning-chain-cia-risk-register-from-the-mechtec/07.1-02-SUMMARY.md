## Deviations from Plan

**1. [Rule 1 - Bug] Row-height strut in the rank cell**
- **Found during:** Task 3 first build
- **Issue:** the planned `\rule{0pt}{18mm}` in the rank cell sets the first-baseline height, so every other cell started 18 mm down and rows grew to about 40 mm; the page overflowed to a sixth page.
- **Fix:** depth strut `\rule[-14.5mm]{0pt}{3.5mm}`, removed the doubled `\vspace` after the category ticks, narrowed the threat column by 1 mm (0.5 pt Overfull).
- **Files modified:** print/templates/teamheft_register.tex.j2
- **Commit:** 2ddd0b2

**2. [Rule 3 - Blocking] `\raggedright` column type**
- **Issue:** plain `p{}` cells justified the narrow cell text with huge gaps.
- **Fix:** added `\newcolumntype{P}` (ragged-right `p` column) to `print/planspiel.sty` and used it for the register table.
- **Commit:** 2ddd0b2

**3. Task 2 RED is a collection error:** the model tests import `MAX_REGISTER_ROWS` and `RANK_FIRST` at module level, so the RED run failed at import rather than per test. The clue guard test is part of that file and passes after GREEN.
