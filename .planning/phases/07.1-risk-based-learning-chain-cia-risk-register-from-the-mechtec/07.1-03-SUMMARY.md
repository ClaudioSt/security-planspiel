# Phase 07.1 Plan 03: "gegen R#" planning column Summary

The Teamheft planning table has a fifth column "gegen R#" where teams may enter one or more register risks per measure, with a hint above the table that marks it as a recommendation (optional, not scored). The measures-block direction in the facilitator booklet points to the column and says the facilitator does not check it; README step 4 names the optional link. Without a risk_matrix (mini fixture) the table keeps four columns and no hint.

## Deviations from Plan

**1. [Rule 1 - Bug] Stray space before the table caused a 1.85 pt Overfull**
- **Found during:** Task 2 first PDF run
- **Issue:** the first template draft put `\setlength{\tabcolsep}{4pt}` and `\begin{tabularx}` on their own lines inside `\BLOCK{if}`; the line ends became spaces in horizontal mode after `\noindent`, so the table paragraph overflowed by 1.85 pt (`no Overfull` test failed). Widening the OPEX column did not change it (reverted to 25 mm).
- **Fix:** `\noindent\begingroup`, the conditional `\setlength` and the `\begin{tabularx}` with its conditional column spec are one line with inline blocks, as in the tracking partial.
- **Files modified:** print/templates/teamheft_planung.tex.j2
- **Commit:** `d7502ac`

**2. [Rule 2 - Missing coverage] Render test also pins the row terminator**
- A body or sum row that lost its `\\` would still pass the `&` count; the render test also asserts every planning row ends with `\\`. Commit `d7502ac`.
