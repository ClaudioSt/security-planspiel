<objective>
FLOW-03: a debrief question set (reaction -> description -> analysis -> application) as part of the facilitator material, timed from config and tied to the game data the facilitator already has (final table, clue matrix, change windows).

Purpose: ROADMAP SC1 (second half). The 20-minute debrief block of the schedule (FLOW-02) needs content a facilitator who did not write the rules can lead.
Output: `session_schedule.debrief_stages` with validator, `planspiel/debrief.py`, `sheets.debrief` texts, a debrief page in `spielleitung-uebersicht`.

Decisions honoured: D-08 (section in the booklet, `sheets.debrief`, no player version), D-09 (fixed questions plus three data prompts), D-10 (transfer questions only), D-11 (2-3 entries per stage, about ten, guide minutes summing to the debrief block), D-27 (team count from config for the comparison rows).

Discretion resolved (CONTEXT "guide minutes per debrief stage"): reaction 3, description 4, analysis 8, application 5 minutes (sum 20 = the debrief block). Analysis gets the most time because it carries two data prompts (clues, change window).

Depends on 07-02 (same files: config block, validator, texts gating, master model and template, the phase-7 number-word lint).

Integration gate (plan check): wave 1 ran three plans with RED tests in flight, so none of them ran the full fast suite. This plan runs it first, before writing any test, and stops on a failure (a wave-1 integration defect is reported, not fixed here).
