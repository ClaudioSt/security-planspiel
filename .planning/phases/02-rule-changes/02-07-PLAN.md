<objective>
Prove and document that an event-induced overrun (Sparprogramm) is penalised only if the team is still over budget after the change window (RULE-05, D-14). With D-14 the single end check is the whole mechanism; this plan pins it with exact scenarios on the path evaluator of plan 02-06, adds a validator warning for budget cuts that no window follows, and states the rule in README and the event description.

Purpose: at MHP teams were unsure whether an external budget cut immediately punished them. The rule must be clear and the simulation must show it on legal games, not on the static reference (which cannot trim and therefore penalises such plans).
Output: `tests/test_sparprogramm.py`, validator warning `rules.event_without_window`, Sparprogramm description sentence, README sentence, PROJECT.md decision row. No golden changes.
</objective>
